## Global Conventions & Error Format

### Authentication
Unless explicitly noted as public, all API endpoints require standard HTTP Bearer token authentication in the `Authorization` header:
```http
Authorization: Bearer <jwt_token>
```

### Standard Error Response Format
All error responses generated by the application follow the `ErrorResponse` schema:
```json
{
  "timestamp": "2026-09-17T04:20:00Z",
  "status": 400,
  "error": "Bad Request",
  "message": "Field 'domain' must not be blank",
  "path": "/api/activities"
}
```

### Common HTTP Status Codes
| Status Code | Meaning | Typical Trigger |
|---|---|---|
| `200 OK` | Request succeeded | Successful GET, PATCH, or login |
| `201 Created` | Resource created | Successful entity creation |
| `400 Bad Request` | Request validation failure | Missing required fields, schema mismatch, out of range values |
| `401 Unauthorized` | Authentication failure | Missing/expired JWT, invalid credentials |
| `403 Forbidden` | Authorization failure | Accessing another user's session/activity/alert, non-ADMIN accessing admin endpoints |
| `404 Not Found` | Resource not found | Target session, activity, policy, or alert ID does not exist |
| `409 Conflict` | Uniqueness conflict | Duplicate email registration or duplicate evidence submission |
| `500 Internal Server Error` | Unhandled server error | Internal unexpected runtime failures |

## 1. Authentication Module (`/api/auth`)

Implemented by `AuthController`.

### `POST /api/auth/register`
Registers a new user account. Defaults to role `ANALYST` if unspecified.

- **Authentication**: None (Public)
- **Request Headers**: `Content-Type: application/json`
- **Request Body**:
```json
{
  "email": "analyst@sentinel.local",
  "password": "SecurePassword123!",
  "companyId": 1
}
```
- **Constraints**:
  - `email`: Not blank, valid email format
  - `password`: Not blank, minimum 8 characters
  - `companyId`: Optional Long
- **Success Response**: `201 Created`
```json
{
  "id": 1,
  "email": "analyst@sentinel.local",
  "role": "ANALYST",
  "companyId": 1,
  "createdAt": "2026-09-17T04:20:00Z"
}
```
- **Error Responses**:
  - `400 Bad Request`: Validation failure on email or password length
  - `409 Conflict`: Email already exists in the system

---

### `POST /api/auth/login`
Authenticates user credentials and issues a JWT token.

- **Authentication**: None (Public)
- **Request Headers**: `Content-Type: application/json`
- **Request Body**:
```json
{
  "email": "analyst@sentinel.local",
  "password": "SecurePassword123!"
}
```
- **Constraints**:
  - `email`: Not blank, valid email format
  - `password`: Not blank
- **Success Response**: `200 OK`
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "expiresIn": 86400,
  "user": {
    "id": 1,
    "email": "analyst@sentinel.local",
    "role": "ANALYST",
    "companyId": 1,
    "createdAt": "2026-09-17T04:20:00Z"
  }
}
```
- **Error Responses**:
  - `400 Bad Request`: Missing credentials
  - `401 Unauthorized`: Invalid email or password

---

### `GET /api/auth/me`
Retrieves the profile of the currently authenticated user.

- **Authentication**: Required (`Bearer <token>`)
- **Request Body**: None
- **Success Response**: `200 OK`
```json
{
  "id": 1,
  "email": "analyst@sentinel.local",
  "role": "ANALYST",
  "companyId": 1,
  "createdAt": "2026-09-17T04:20:00Z"
}
```
- **Error Responses**:
  - `401 Unauthorized`: Missing or invalid Bearer token

## 2. Browser Telemetry Module (`/api`)

Implemented by `BrowserController`. Users can only view and manipulate their own browser sessions and activities.

### `POST /api/sessions`
Creates an `ACTIVE` browser session for the current authenticated user.

- **Authentication**: Required (`Bearer <token>`)
- **Request Body**: None
- **Success Response**: `201 Created`
```json
{
  "id": 10,
  "startedAt": "2026-09-17T04:25:00Z",
  "status": "ACTIVE",
  "createdAt": "2026-09-17T04:25:00Z"
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated

---

### `PATCH /api/sessions/{id}/end`
Closes an existing active browser session by setting `status = "CLOSED"` and `endedAt`.

- **Authentication**: Required (`Bearer <token>`)
- **Path Parameters**:
  - `id` (Long): The session ID
- **Request Body**: None
- **Success Response**: `200 OK`
```json
{
  "id": 10,
  "userId": 1,
  "startedAt": "2026-09-17T04:25:00Z",
  "endedAt": "2026-09-17T04:55:00Z",
  "status": "CLOSED",
  "createdAt": "2026-09-17T04:25:00Z"
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Session belongs to another user
  - `404 Not Found`: Session ID does not exist

---

### `GET /api/sessions`
Retrieves a paginated list of browser sessions for the current authenticated user.

- **Authentication**: Required (`Bearer <token>`)
- **Query Parameters**:
  - `page` (int, default `0`): Page index
  - `size` (int, default `20`): Page size
  - `sort` (string, default `startedAt,DESC`): Sorting order
- **Request Body**: None
- **Success Response**: `200 OK` (Spring Page format)
```json
{
  "content": [
    {
      "id": 10,
      "userId": 1,
      "startedAt": "2026-09-17T04:25:00Z",
      "endedAt": "2026-09-17T04:55:00Z",
      "status": "CLOSED",
      "createdAt": "2026-09-17T04:25:00Z"
    }
  ],
  "pageable": { "pageNumber": 0, "pageSize": 20 },
  "totalElements": 1,
  "totalPages": 1,
  "last": true,
  "size": 20,
  "number": 0
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated

---

### `POST /api/activities`
Creates a browser activity record associated with an existing active session. Automatically computes `durationSeconds` if `endedAt` is provided.

- **Authentication**: Required (`Bearer <token>`)
- **Request Headers**: `Content-Type: application/json`
- **Request Body**:
```json
{
  "sessionId": 10,
  "domain": "chatgpt.com",
  "url": "https://chatgpt.com/c/project-analysis",
  "pageTitle": "ChatGPT - Project Analysis",
  "startedAt": "2026-09-17T04:26:00Z",
  "endedAt": "2026-09-17T04:29:00Z"
}
```
- **Constraints**:
  - `sessionId`: Not null
  - `domain`: Not blank, max 255 chars
  - `url`: Optional, max 500 chars
  - `pageTitle`: Optional, max 255 chars
  - `startedAt`: Not null
  - `endedAt`: Optional
- **Success Response**: `201 Created`
```json
{
  "id": 101,
  "sessionId": 10,
  "domain": "chatgpt.com",
  "url": "https://chatgpt.com/c/project-analysis",
  "pageTitle": "ChatGPT - Project Analysis",
  "startedAt": "2026-09-17T04:26:00Z",
  "endedAt": "2026-09-17T04:29:00Z",
  "durationSeconds": 180,
  "createdAt": "2026-09-17T04:26:00Z"
}
```
- **Error Responses**:
  - `400 Bad Request`: Validation failure on required fields
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: `sessionId` belongs to another user
  - `404 Not Found`: `sessionId` does not exist

---

### `GET /api/activities`
Retrieves a paginated, filterable list of browser activities for the current authenticated user.

- **Authentication**: Required (`Bearer <token>`)
- **Query Parameters**:
  - `sessionId` (Long, optional): Filter by session ID
  - `domain` (string, optional): Filter by exact domain
  - `from` (ISO Instant, optional): Activities started at or after this timestamp
  - `to` (ISO Instant, optional): Activities started at or before this timestamp
  - `page` (int, default `0`): Page index
  - `size` (int, default `20`): Page size
  - `sort` (string, default `startedAt,DESC`): Sorting order
- **Success Response**: `200 OK` (Spring Page of `BrowserActivityResponse`)
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated

## 3. Classification & Evidence Module (`/api/classification`)

Implemented by `ClassificationController`. Handles the frozen 18-signal evidence contract and ML inference results.

### `POST /api/classification/evidence`
Ingests telemetry signals for an activity. Persists `ClassificationEvidence`, immediately initiates ML classification via `MlClient`, records `ClassificationResult`, and fires a `ClassificationCompletedEvent` triggering risk analysis.

- **Authentication**: Required (`Bearer <token>`)
- **Request Headers**: `Content-Type: application/json`
- **Request Body**:
```json
{
  "activityId": 101,
  "schemaVersion": "v1",
  "capturedAt": "2026-09-17T04:29:00Z",
  "domainLength": 11,
  "visitCount": 3,
  "durationSeconds": 180,
  "isKnownAiDomain": true,
  "hourOfDay": 14,
  "pathDepth": 2,
  "chatInterfacePresent": true,
  "promptInputPresent": true,
  "generateControlPresent": true,
  "regenerateControlPresent": true,
  "aiTermCount": 5,
  "streamingOutputPresent": true,
  "fileUploadPresent": true,
  "promptSubmitCount": 3,
  "generateClickCount": 4,
  "pasteEventCount": 2,
  "copyFromResponseCount": 1,
  "typedCharCountBucket": 3
}
```
- **Constraints**:
  - `activityId`: Not null
  - `capturedAt`: Not null
  - `hourOfDay`: 0 to 23
  - `typedCharCountBucket`: 0 to 4 (bucketed: 0=0, 1=1-50, 2=51-200, 3=201-1000, 4=1001+)
- **Success Response**: `201 Created`
```json
{
  "id": 50,
  "activityId": 101,
  "schemaVersion": "v1",
  "capturedAt": "2026-09-17T04:29:00Z",
  "createdAt": "2026-09-17T04:29:00Z",
  "domainLength": 11,
  "visitCount": 3,
  "durationSeconds": 180,
  "isKnownAiDomain": true,
  "hourOfDay": 14,
  "pathDepth": 2,
  "chatInterfacePresent": true,
  "promptInputPresent": true,
  "generateControlPresent": true,
  "regenerateControlPresent": true,
  "aiTermCount": 5,
  "streamingOutputPresent": true,
  "fileUploadPresent": true,
  "promptSubmitCount": 3,
  "generateClickCount": 4,
  "pasteEventCount": 2,
  "copyFromResponseCount": 1,
  "typedCharCountBucket": 3
}
```
- **Error Responses**:
  - `400 Bad Request`: Field validation error (e.g., `hourOfDay > 23` or `typedCharCountBucket > 4`)
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Target activity belongs to another user
  - `404 Not Found`: Target activity does not exist
  - `409 Conflict`: Evidence has already been submitted for this activity

---

### `GET /api/classification/evidence/{activityId}`
Retrieves the ingested raw evidence signals for a specific activity.

- **Authentication**: Required (`Bearer <token>`)
- **Path Parameters**: `activityId` (Long)
- **Success Response**: `200 OK` (`ClassificationEvidenceResponse` schema shown above)
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Activity belongs to another user
  - `404 Not Found`: Evidence not found for given activity ID

---

### `GET /api/classification/results/{activityId}`
Retrieves the ML classification inference result for an activity.

- **Authentication**: Required (`Bearer <token>`)
- **Path Parameters**: `activityId` (Long)
- **Success Response**: `200 OK`
```json
{
  "id": 42,
  "activityId": 101,
  "classLabel": "AI_GENERATION",
  "confidence": 0.965,
  "modelVersion": "v1",
  "createdAt": "2026-09-17T04:29:01Z"
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Activity belongs to another user
  - `404 Not Found`: Result not found for given activity ID

---

### `GET /api/classification/results`
Retrieves a paginated list of classification results for the current user.

- **Authentication**: Required (`Bearer <token>`)
- **Query Parameters**:
  - `label` (`NON_AI`, `AI_CAPABLE_PAGE`, `AI_INTERACTION`, `AI_GENERATION`, optional)
  - `from` (ISO Instant, optional)
  - `to` (ISO Instant, optional)
  - `page` (int, default `0`)
  - `size` (int, default `20`)
  - `sort` (string, default `createdAt,DESC`)
- **Success Response**: `200 OK` (Spring Page of `ClassificationResultResponse`)
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated

Implemented by `RiskController` and `PolicyController`. Evaluates activities deterministically against active company policies.

Retrieves the evaluated risk assessment for an activity.

- **Authentication**: Required (`Bearer <token>`)
- **Path Parameters**: `activityId` (Long)
- **Success Response**: `200 OK`

```json
  "policyVersion": 1,
  "modelVersion": "v1",
  "createdAt": "2026-09-17T04:29:01Z"
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Activity belongs to another user
  - `404 Not Found`: Risk assessment not found

---

### `GET /api/risk`

- **Query Parameters**:

  - `sort` (string, default `createdAt,DESC`)

- **Error Responses**:
  - `401 Unauthorized`: Not authenticated

### `POST /api/policies/rules`
Adds a new evaluation rule to an existing company policy. Automatically increments policy `version`.

- **Authentication**: Required (`Bearer <token>`, Role: `ADMIN`)
- **Request Headers**: `Content-Type: application/json`
- **Request Body**:
```json
{
  "policyId": 1,
  "ruleKey": "RULE_RESTRICTED_DOMAIN",
  "appliesToLabel": "AI_GENERATION",
  "domainPattern": "*.internal-leak.com",

  "requiresPasteEvent": true,
  "severity": "CRITICAL",
  "scoreWeight": 35,
  "description": "Generation and paste on restricted domain"
}
```
- **Constraints**:
  - `policyId`: Not null
  - `ruleKey`: Not blank
  - `severity`: Not null (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`)
  - `scoreWeight`: Between 0 and 40
  - `description`: Not blank
- **Success Response**: `201 Created`
```json
{
  "id": 7,
  "policyId": 1,
  "ruleKey": "RULE_RESTRICTED_DOMAIN",
  "appliesToLabel": "AI_GENERATION",
  "domainPattern": "*.internal-leak.com",
  "minGenerateClicks": 1,
  "requiresFileUpload": false,
  "requiresPasteEvent": true,
  "severity": "CRITICAL",
  "scoreWeight": 35,
  "description": "Generation and paste on restricted domain"
}
```
- **Error Responses**:
  - `400 Bad Request`: Validation failure on input parameters
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Non-admin user
  - `404 Not Found`: Policy ID does not exist

## 5. Alerts Module (`/api/alerts`)

Implemented by `AlertController`. Created automatically when risk level is `HIGH` or `CRITICAL`. Features deduplication within 30 minutes for identical user, domain, and severity.

### `GET /api/alerts`
Retrieves a paginated list of alerts. Regular users see only their alerts; `ADMIN` users see all enterprise alerts across users.

- **Authentication**: Required (`Bearer <token>`)
- **Query Parameters**:
  - `status` (`NEW`, `ACKNOWLEDGED`, `RESOLVED`, optional)
  - `severity` (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`, optional)
  - `page` (int, default `0`)
  - `size` (int, default `20`)
  - `sort` (string, default `createdAt,DESC`)
- **Success Response**: `200 OK`
```json
{
  "content": [
    {
      "id": 1,
      "userId": 1,
      "activityId": 101,
      "domain": "chatgpt.com",
      "riskAssessmentId": 30,
      "severity": "CRITICAL",
      "title": "CRITICAL Risk Detected on chatgpt.com",
      "message": "Final risk level: CRITICAL; Matched rules: [RULE_FILE_UPLOAD, RULE_CRITICAL_DATA_EXFIL]",
      "status": "NEW",
      "occurrenceCount": 1,
      "createdAt": "2026-09-17T04:29:01Z",
      "acknowledgedAt": null
    }
  ],
  "pageable": { "pageNumber": 0, "pageSize": 20 },
  "totalElements": 1,
  "totalPages": 1,
  "last": true
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated

---

### `PATCH /api/alerts/{id}/acknowledge`
Transitions alert status to `ACKNOWLEDGED` and sets `acknowledgedAt = now()`. Logs audit event `ALERT_ACKNOWLEDGED`.

- **Authentication**: Required (`Bearer <token>`)
- **Path Parameters**: `id` (Long)
- **Success Response**: `200 OK`
```json
{
  "id": 1,
  "userId": 1,
  "activityId": 101,
  "domain": "chatgpt.com",
  "riskAssessmentId": 30,
  "severity": "CRITICAL",
  "title": "CRITICAL Risk Detected on chatgpt.com",
  "message": "Final risk level: CRITICAL; Matched rules: [RULE_FILE_UPLOAD, RULE_CRITICAL_DATA_EXFIL]",
  "status": "ACKNOWLEDGED",
  "occurrenceCount": 1,
  "createdAt": "2026-09-17T04:29:01Z",
  "acknowledgedAt": "2026-09-17T04:35:12Z"
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Alert belongs to another user (and caller is not admin)
  - `404 Not Found`: Alert ID does not exist

---

### `PATCH /api/alerts/{id}/resolve`
Transitions alert status to `RESOLVED`.

- **Authentication**: Required (`Bearer <token>`)
- **Path Parameters**: `id` (Long)
- **Success Response**: `200 OK` (Status updated to `RESOLVED`)
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Alert belongs to another user (and caller is not admin)
  - `404 Not Found`: Alert ID does not exist

## 6. Audit Logging Module (`/api/audit`)

Implemented by `AuditController`. Exposes immutable security audit records logged across system operations.

### `GET /api/audit`
Retrieves a paginated, filterable stream of audit log entries.

- **Authentication**: Required (`Bearer <token>`, Role: `ADMIN`)
- **Query Parameters**:
  - `eventType` (AuditEventType enum, optional):
    - `LOGIN`, `LOGIN_FAILED`, `SESSION_STARTED`, `EVIDENCE_INGESTED`, `CLASSIFICATION_CREATED`, `RISK_ASSESSED`, `ALERT_CREATED`, `ALERT_ACKNOWLEDGED`, `POLICY_CHANGED`
  - `userId` (Long, optional): Filter by user ID
  - `from` (ISO Instant, optional)
  - `to` (ISO Instant, optional)
  - `page` (int, default `0`)
  - `size` (int, default `20`)
  - `sort` (string, default `createdAt,DESC`)
- **Success Response**: `200 OK`
```json
{
  "content": [
    {
      "id": 1,
      "userId": 1,
      "eventType": "ALERT_CREATED",
      "targetId": "1",
      "details": "Alert created: CRITICAL Risk Detected on chatgpt.com",
      "createdAt": "2026-09-17T04:29:01Z"
    },
    {
      "id": 2,
      "userId": 1,
      "eventType": "EVIDENCE_INGESTED",
      "targetId": "50",
      "details": "Classification evidence ingested for activity 101",
      "createdAt": "2026-09-17T04:29:00Z"
    }
  ],
  "pageable": { "pageNumber": 0, "pageSize": 20 },
  "totalElements": 2,
  "totalPages": 1,
  "last": true
}
```
- **Error Responses**:
  - `401 Unauthorized`: Not authenticated
  - `403 Forbidden`: Caller lacks `ROLE_ADMIN` authority
